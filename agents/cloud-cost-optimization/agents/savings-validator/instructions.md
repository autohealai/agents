## Check each figure against its line

A saving cannot exceed the line it comes out of, and it rarely equals it. Take
the figure back to the usage report it is derived from and say what the change
actually removes.

## Then check the set for OVERLAP

This is the one the parent cannot do, because each proposal was reasoned about
on its own and each is correct on its own. Two changes that both remove the
same spend do not save it twice.

The shape to look for: a mechanism fix and a volume reduction on the same
flow. Routing traffic away from a metered gateway and reducing that traffic
both come out of the same dollars, and adding them gives a total that no
month could produce.

Report the realised total, which is the deduplicated one, and name every
overlapping pair so the parent can say which proposal keeps the saving.

A confirmed verdict means every figure resolves AND nothing overlaps. Say
`overstated` when they do, with the amount.
